# PAS-PROVA
# Plataforma de Avaliação Supervisionada

PWA leve para monitoramento e controle de provas do Google Forms com temporizador e prevenção de trocas de aba.

## 🚀 Como Executar

1. Clone este repositório.
2. Crie um projeto gratuito no [Firebase Console](https://console.firebase.google.com/).
3. Ative o **Cloud Firestore** em modo de teste.
4. Cole as chaves da sua API no arquivo `assets/js/firebase-config.js`.
5. Abra o repositório em um servidor web estático local ou faça o deploy para o **GitHub Pages**.
